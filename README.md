# AI PR Review 助手 (AI PR Review Assistant)

## 项目简介

一款基于大模型辅助的 GitHub Pull Request 自动化审查工具，旨在帮助开发者提升代码 Review 的效率与质量，精准识别潜在的深层代码隐患。

## 核心技术栈

- 前端框架：React 18 + Vite + TypeScript
- 样式方案：Tailwind CSS (待接入)
- 核心引擎：GitHub REST API, 大语言模型 API (LLM)

## 本地运行指南

1. 克隆项目到本地
2. 安装依赖：`npm install`
3. 启动开发服务器：`npm run dev`
